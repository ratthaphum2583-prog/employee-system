# Employee System

A Python employee management project for practicing data processing,
business logic, modular project structure, and reporting.

## Features

- View active employees
- Search employee by name
- Find the employee with the highest salary
- Calculate employee bonuses
- Build employee reports
- Summarize employees by department
- Find the employee with the highest bonus

## Bonus Rules

- Active employee with salary >= 30,000: 10% bonus
- Active employee with salary < 30,000: 5% bonus
- Inactive employee: 0% bonus
